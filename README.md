# Enterprise Data Platform

## Overview
This project implements an enterprise-grade data platform to ingest, transform,
and load business data into a cloud-based data warehouse for analytics.

## Tech Stack
- Python / PySpark
- AWS S3
- Airflow
- Snowflake / Redshift

## Project Structure
- dags/ : Airflow DAGs
- src/  : ETL logic
- configs/ : Environment configs
- data/ : Sample input data
